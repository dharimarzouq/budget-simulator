# UK Data Service: registration and question

Steps for Ari. Nothing here has been sent.

## 1. Register

Register at https://ukdataservice.ac.uk/ using the option for users without a university login (independent researchers are listed as eligible). Accept the End User Licence. Read the licence text before accepting, especially the parts on publication and on sharing outputs.

## 2. Request the Family Resources Survey

Request the latest FRS End User Licence edition (2023/24 at time of writing). Check its catalogue record for any special conditions, such as publication clearance.

## 3. Ask the publishing question

Send this to the UK Data Service help desk (contact form on their site). Edit freely.

> Subject: Using FRS End User Licence data in a non-commercial public policy tool
>
> Hello,
>
> I'm building a free, open-source, non-commercial website that lets people explore changes to UK tax and benefit policy and see the estimated effect on households, similar to published distributional analysis.
>
> I'd like to use the Family Resources Survey (End User Licence edition) as the household sample. The microdata would stay on a private server and never be published, shared or sent to users' browsers. The website would show only aggregate results, such as average gains and losses by income decile, region or family type, with a minimum cell size and rounding to prevent disclosure.
>
> Because users choose the policy changes, these aggregates would be computed on request rather than pre-published.
>
> Could you tell me:
> 1. Whether this use is allowed under the End User Licence, and under what conditions (minimum cell sizes, rounding, output checking, citation)?
> 2. Whether the FRS has any special conditions, such as publication clearance, that would apply?
> 3. If the End User Licence doesn't cover this, whether another route would?
>
> Thank you,
> Ari

## Why this matters

If the answer is yes, the winners and losers layer can switch from the synthetic population to the FRS. That would mean a small always-on server (a cost). If it's no, the synthetic population stays and the site stays fully static.
